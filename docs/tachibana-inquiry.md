# 立花証券 e 支店 API の利用についての問い合わせ（下書き）

取り込み元に立花証券 e 支店 API を使う前に、その使い方が規約の範囲内かを立花証券に確かめるための文面（#133）。送るのは口座を持つ利用者本人。e 支店のお問い合わせ窓口（ログイン後のお問い合わせフォームなど）から送る。

## 確かめる理由

- API のご案内（`https://www.e-shiten.jp/e_api/mfds_json_api_menu.html` の「利用上の注意」7 項）に「当社提供情報は、蓄積、編集および加工等は禁止」とある
- インターネット取引規程（`https://www.e-shiten.jp/TorihikiRule/stipulation/pdf/int_kitei.pdf`）の第 18 条は、情報サービスの利用を「お客様の証券投資のためにのみ」に限り、第三者への提供・第三者へ提供する目的での加工や再利用を禁じている
- このツールは、取得した時価を BigQuery に貯め、IV を計算し、ビューアーで見る。自分のためだけに使う場合でも「蓄積・加工」に当たるかは、文面からは決まらない

返事の内容は、個人の情報を除いて #133 に記録する。

## 文面

`＿＿＿＿` の所は送る人が埋める（リポジトリには書かない）。

---

**件名**: e 支店 API の利用方法が規約の範囲内かのご確認

立花証券 e 支店 ご担当者様

いつもお世話になっております。口座番号 ＿＿＿＿ の ＿＿＿＿ です。

e 支店 API の利用を考えております。次の使い方が、API のご案内の「当社提供情報は、蓄積、編集および加工等は禁止」と、インターネット取引規程の第 18 条の範囲内かをお教えください。

**考えている使い方**

1. 自分の口座で API にログインし、日経225 オプションと日経225 先物の時価、日経平均を取得します
   - 取得するのは 1 分に 1 回、取引時間中だけです
   - 1 回あたりの要求は 10 件程度で、秒 10 件の上限は守ります
2. 取得した時価を、自分で契約しているクラウド（Google Cloud）の領域に保存します
3. 保存した時価から、自分でインプライド・ボラティリティなどを計算し、グラフにして自分で見ます。目的は、自分の日経225 オプションの売買の判断です
4. 時価も計算の結果も、第三者には一切見せません。グラフの画面は自分しかログインできない設定にしてあり、配信・転載・販売もしません

**お伺いしたいこと**

1. 上の 1〜4 の使い方は、規約の範囲内でしょうか
2. 範囲外の場合、どこまでなら認められるでしょうか。例えば、保存する期間を限る、計算の結果だけを残す、などです
3. この取得と保存のためのプログラムを、自作のソフトウェアの一部としてインターネット上に公開することは差し支えないでしょうか
   - 公開するのはプログラムだけです。時価のデータや、私の認証情報は含みません
   - 利用者はそれぞれ自分の口座で使う前提です
4. （技術的なご質問で恐縮ですが、可能でしたら）次の 2 点も教えてください
   - 銘柄マスタの商品区分（sSakOpSyouhin）で、日経225 オプション（月次）を表す値
   - 週次オプションとミニオプションの見分け方

お手数をおかけしますが、よろしくお願いいたします。
